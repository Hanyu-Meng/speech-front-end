02 · METHOD LANDSCAPE

生成，还是映射？

两条路线不是简单的新旧替代。生成式模型更会“补全”，判别式模型更擅长“忠实映射”；混合式方法正在把二者组合。

G GENERATIVE

学习干净语音的分布

退化语音 + 条件→扩散 / LM / Flow→采样或再生

扩散与 score-based 方法以多步去噪求高自然度；离散 token LM 借语义上下文“重说”内容；flow matching 和一致性模型尝试把生成路径压短。

优势
强语音先验、主观自然度、未见噪声泛化潜力
问题
幻觉或内容改写、音色漂移、采样延迟、随机不稳定
D DISCRIMINATIVE

学习退化到目标的映射

波形 / 复谱→Mask / Mapping / Beam→确定性输出

时域 TasNet、复数谱映射、时频 Transformer 和神经波束形成仍是实时与多通道系统的主力，输出可重复且容易控制算力。

优势
单次前向、内容更可控、因果实现成熟、部署成本低
问题
过平滑、配对数据依赖、域外退化、对未见声学条件脆弱
H

更值得关注的交汇点： predict-then-diffuse、神经网络 + FCP/WPE/MVDR、任务解耦级联。它们用物理或判别式锚点约束生成自由度，但会引入级联误差和系统复杂度。

按任务展开详细方法与问题
任务非生成式主线生成式主线最需要警惕
语音增强CRN / Conformer；复数谱映射；全带 + 子带；神经波束形成条件扩散、score-SDE、一致性模型、语音 token LM、flow matching感知分数提高却伤害 WER；生成内容与原话不一致
目标说话人提取SpeakerBeam / SpEx；TasNet；视觉、方向、HRTF 条件；多通道 beamforming说话人条件扩散、ensemble sampling、个性化 score model错人比残余噪声更严重；目标不活跃时的虚假输出
去混响WPE / FCP；DNN + 线性预测；复谱映射；多通道空间网络score-based regeneration 与增强联合建模直达声被削弱；仿真 RIR 与真实房间失配；移动时滤波器失效
回声消除自适应滤波 + 神经后滤波；端到端 TCN/RNN；cross-attention 对齐远端条件 score model；快速单步 diffusion双讲近端损伤、参考时延漂移、扬声器非线性；生成式证据仍少

03 · METRIC ATLAS

不要让一个分数决定一切

建议每个系统至少同时报告：保真 + 感知 + 可懂度/下游 + 运行代价；生成式系统再加身份与内容一致性。

SE语音增强SI-SDR · DNSMOS · STOI · WER
  • 保真 SI-SDR / SDR
  • 质量 POLQA、DNSMOS P.835、MOS
  • 可懂度 STOI / ESTOI、WER / WAcc
  • 部署 RTF、MACs、参数量、算法延迟

PESQ 已被 ITU 标为过时；不能只报 PESQ。

TSE目标说话人提取SI-SDRi · 身份 · 混淆率
  • 分离 SI-SDRi / SDRi、PESQ、STOI
  • 身份 speaker similarity、target confusion
  • 下游 WER / CER、说话人验证
  • 空目标 泄漏能量、false extraction

平均 SI-SDR 会掩盖“选错人”，应单报目标混淆率。

DR去混响SRMR · T60 · DRR · WER
  • 保真 SI-SDR、PESQ、STOI / ESTOI
  • 混响 SRMR、晚期混响能量
  • 房间 T60 / DRR 估计误差
  • 下游 远场 ASR WER

SRMR 是无参考代理，最好配合真实房间 ASR。

AEC回声消除ERLE · AECMOS · 双讲
  • 回声 ERLE、AECMOS Echo
  • 近端 POLQA、STOI、AECMOS Other
  • 通信 MOS、WAcc / WER
  • 场景 单讲 / 双讲、时延与非线性分桶

ERLE 只适合远端单讲；双讲应优先看近端保真。

指标依据：SI-SDR ↗DNSMOS P.835 ↗AECMOS ↗ITU PESQ 状态 ↗HASPI / HASQI ↗
